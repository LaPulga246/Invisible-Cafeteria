🛡️ The Golden Safety Rule (Non-Negotiable)

Only operator-verified food-safety data, approved handling windows, and verified cold-chain logs can authorise redistribution. Food is NEVER inferred to be safe simply because it has not been collected yet. If safe handling time lapses, the batch is instantly locked down.

1. Demand Forecasting Stat Model

Weighted moving average of recent same-weekday lunch volumes (weights 4, 3, 2, 1) + damped trend + campus calendar adjustments (Fest, Exams, Holidays) with an 80% confidence interval.

2. Surplus & HACCP Sensing Cold-Chain Guard

Surplus trays logged with exact timestamps, shelf-life countdowns, portion quantities, verified allergen tags, and real-time HACCP temperature telemetry (>60°C hot-hold).

3. Capacity & Split Matching Dynamic Route

Earliest-expiry first matching with intelligent batch splitting across open campus pantries, preventing over-allocation and adhering to dietary safety filters.

🎯 The Two Hackathon Constraints Under Evaluation Official Defense

Our architecture is deliberately engineered to handle ambiguity and protocol breakage in production environments. Below are the live mechanisms for both constraints.

Constraint Card 12: Missing Decisive Fact Rule Applied
"The system has enough information to generate possible actions but not enough information to safely choose one. The scenario intentionally omits one decision-critical fact."

Implementation: In batch S9 (Mixed Pulao), the food is verified and the handling window is valid, but the Allergen Declaration is omitted. The system calculates all candidate collection points and their transit windows, but refuses to commit to any route. Instead, it computes and displays the counterfactual impact of the missing fact:

Live Inspection: Batch S9 (Mixed Pulao)

Status: Decision Needed

Omitted Fact: Allergen Declaration (Undefined)

What the missing fact would change:
• If Allergens = "None (Clean)" → 4/4 Collection Points qualify. Batch is routed to Student Union Hub.
• If Allergens = "Contains Peanuts / Nuts" → Only 1/4 Points qualify (East Dorm dedicated allergy pantry).
• If Allergens = "Contains Dairy" → 2/4 Points qualify.
